# 八字排盘 · 命理测算

基于 GitHub 开源排盘引擎 [lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT 协议）开发的纯前端八字测算 Web 应用。无需安装、无需后端，浏览器打开即用，所有计算均在本地完成。

## 在线使用

**https://wegene38.github.io/bazi/**（GitHub Pages 托管，支持手机 / 电脑浏览器）

## 手机上"装"成 App（添加到主屏幕）

本站是 PWA，添加到主屏幕后以独立窗口打开、带印章图标、**离线也能用**（首次联网加载后所有排盘计算均在手机本地完成）：

- **iPhone（Safari）**：打开上面的网址 → 底部「分享」按钮 →「添加到主屏幕」→「添加」
- **Android（Chrome）**：打开网址 → 地址栏右侧「⋮」菜单（或安装提示横幅）→「添加到主屏幕 / 安装应用」
- 微信内打开无法添加主屏幕，请点右上角「···」选择「在浏览器打开」后再操作

## 功能

- **生辰录入**：公历 / 农历（含闰月）双历法输入，时辰实时提示，可选真太阳时校正（按出生地经度 + 均时差）
- **四柱排盘**：年月日时四柱干支、天干十神、地支藏干（含十神）、地势（长生十二神）、纳音、空亡、胎元、命宫、身宫、生肖、星座
- **五行分析**：五行分布图（天干每字 100 分，地支藏干按本气 60 / 中气 30 / 余气 10 加权），日主强弱判定（同类占比 + 得令 / 得地修正），喜用神建议
- **大运流年**：起运时间、10 步大运（顺逆按阳男阴女规则）、逐步大运可展开流年，起运前显示小运，当前大运 / 当前流年自动标出
- **职业推荐**：以喜用五行行业、十神心性分布、月令格局、神煞（文昌 / 驿马 / 华盖）、日主强弱五类依据加权评分，输出 TOP5 职业方向（含适任职业、依据标签）与相对费力方向的温和提示
- **命理解读**：总评、日主性格（十天干）、格局（月令取格）、事业方向（官杀 + 喜用五行行业）、财运（财星与身强弱配合）、婚姻（夫妻宫 + 男财女官 + 咸池桃花）、当前大运简评

## 快速开始

纯静态页面，直接双击 `index.html` 即可使用；或起一个本地服务：

```bash
cd 八字
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 项目结构

```
├── index.html          # 页面结构（输入表单 + 结果区）
├── css/style.css       # 中式古典风样式（宣纸底 / 朱砂红 / 描金）
├── js/app.js           # 表单交互、排盘调用与渲染
├── js/analysis.js      # 解读规则库：十神推算、五行计分、强弱、喜用、文案
├── lib/lunar.js        # lunar-javascript 排盘引擎（MIT）
├── icons/              # PWA 图标（印章风）
├── manifest.webmanifest# PWA 应用清单
├── sw.js               # Service Worker（离线缓存）
└── test/verify.js      # 命例核对脚本（Node）
```

## 命例核对

```bash
node test/verify.js
```

覆盖官方文档命例（1986-05-29 13:37 男 → 丙寅 癸巳 癸酉 己未）、早子时跨年柱、农历闰月转换、十神推算交叉验证（对照 lunar 内置结果）、真太阳时公式精度等。

## 口径说明

- 晚子时按 lunar 默认流派 2（晚子时日柱算当天）
- 五行计分与日主强弱为**简化模型**，未做调候、合冲刑害、特殊格局等精细分析
- 命理解读由规则化文案自动生成，**仅供参考娱乐**，不构成任何人生决策建议
